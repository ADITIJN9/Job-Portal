# Job Portal Website

A responsive Job Portal website built using **HTML, CSS, and JavaScript**.

## About the Project

This project provides a simple and interactive platform where users can explore job opportunities, browse job categories, and find relevant job listings.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Interactive functionality

## Features

- Clean and user-friendly interface
- Job listings section
- Job categories
- Search and filter functionality
- Apply Now section
- Responsive design

## Project Structure

```text
Job-Portal/
└── Job-Portal.html
```

## How to Run

1. Download or clone this repository.
2. Open `Job-Portal.html` in your browser.
3. Explore the Job Portal website.
